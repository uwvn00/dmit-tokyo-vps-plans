## 三条线到底差在哪，贵的那部分钱花在什么上

差别只在回国的路由上，CPU、内存、硬盘三套配置是同一套硬件池。

**TYO Premium（Pro）** 是旗舰线。去程电信走 CN2 GIA、联通走 AS9929、移动走 CMI，三网回程强制 CN2 GIA。这是大陆访问体验最稳的组合，代价是价格，TINY 起步就是 $21.90/月，而且流量配额是三条线里最紧的，500GB/月。

**TYO Eyeball（EB）** 走三网 CMI/CMIN2。CMI 是中国移动国际线路，移动用户直连效果好，电信联通也做了针对性处理。整体不如 Pro 极致，但同档配置下带宽给得更大方，MICRO 档直接给到 4Gbps，流量也翻倍。

**TYO Tier 1（T1）** 是国际线路，没有大陆优化。电信联通走 NTT，偶发绕美经 Lumen，移动走 CMI，不保证回国速度。它的价值在于便宜和流量多：WEE 年付 $36.90，MICRO 档 $32.90/月就给 16TB 月流量。

| 电信（上海方向） | 约 60–80ms | 平均 150–180ms |
| 联通（北京方向） | 约 50–65ms | 同上 |

Pro 在晚高峰基本维持在同一区间，不会出现白天 80ms、晚上 200ms 的落差，这是 CN2 GIA 回程带来的稳定性。T1 的实际延迟取决于当时路由，测出来多少就是多少。

## 超量、换 IP 和退款：三条容易被忽略的规则

这三件事只看套餐表看不出来，但会直接影响你用起来顺不顺。

**流量用完之后怎么办。** Pro 和 Eyeball 是停机，必须等下个周期重置或另购流量，业务型用户要提前留意用量。T1 是降速不停机，1Gbps 掉到 50Mbps 之后日常刷网页还能用，跑大文件就别想了。

**IP 被封能不能换。** Pro 和 Eyeball 每 15 天可申请一次免费换 IP，前提是 IP 确实被封，不能因为想换就换。T1 没有这项承诺。

**退款有两个时间窗。** 3 天内无理由全额退，条件是流量使用不超过 30GB；超过 3 天按剩余价值比例退，窗口是 30 天。不走退款流程的情况有几种：续费订单、用账户余额支付的订单、同一系列产品已经退款达到 3 次、以及 IP 被封导致的不可用。退款可选原路返回（可能扣手续费）或退到账户余额（免手续费），后者更划算但钱留在账户里。

新用户先月付跑一个周期再决定年付，这条建议不只是为了保险，也是因为这几条线的路由差异只有在你自己的网络环境里跑过才知道。

## 哪些人不该买 DMIT 东京

**纯日本本地业务。** 面向日本用户的网站、面向日本市场的应用，用不到 CN2 GIA 回程。T1 的本地连接速度足够，价格只有 Pro 的零头。买 Pro 属于为一条用不上的线路付钱。

**只需要一个日本 IP 的人。** 注册日区账号、跑个轻量脚本、做个跳板，T1 的 WEE 年付 $36.90 就办完了。同样的钱买 Pro 只够一个多月的月付。

**预算卡得很紧的。** 日本 NTT 线路的普通 VPS 价格通常只有 Pro 的 1/2 到 1/3，代价是没有大陆优化。如果你的访问者主要在境外，这笔差价没必要花。

**指望它解锁日区流媒体的。** 第三方反馈显示，Netflix 日区可用，但 Abema、Hulu Japan 需要额外配置才能看。宣传里"全网解锁"的说法不要当承诺，具体片子自己测。

顺带说一个常被拿来比较的对象：搬瓦工。DMIT 是搬瓦工的上游供应商之一，两家都做 CN2 GIA，区别在于 DMIT 走自有网络、不超售，线路更纯粹；搬瓦工的 CN2 GIA 套餐流量通常给得更多，价格相对亲民。要极致线路选前者，要大流量配额选后者，这个判断跟预算关系不大，跟用途关系更大。

## 香港和东京怎么取舍

香港 Pro 到大陆最低能到 20–30ms，东京 Pro 在 60–80ms，差距是肉眼可感的，尤其对实时交互类应用。价格上香港 Pro 入门 $39.90/月，东京 Pro 入门 $21.90/月，接近两倍差价。

预算充足、延迟是硬指标，选香港。要日本原生 IP、或者想把成本压下来，东京这条线更实际。香港节点缺货时，东京 Pro 是最接近的替代。
